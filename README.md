# Welcome!

## What is m3u8?

An M3U8 file for TV is a plain-text playlist format used to stream live television channels over the internet via HTTP Live Streaming (HLS). Instead of containing actual video data, the file acts as a lightweight directory that tells media players where to find and play live broadcast streams.

## How It Works

• Text-Based Playlist. The file uses UTF-8 encoding and contains a structured list of web addresses (URLs) alongside metadata like channel names, categories, and stream durations.

• Segmented Streaming. Rather than loading a single massive video file, M3U8 breaks live broadcasts into small, sequential chunks lasting just a few seconds each. If your internet connection dips momentarily, the player only loses a brief segment rather than dropping the entire feed.

• Adaptive Bitrate. M3U8 playlists often bundle multiple resolution and bandwidth options for the same channel. This allows your player to automatically adjust video quality in real time based on your internet speed.

## Common Uses & Players

• IPTV & Live Broadcasts. Broadcasters and IPTV apps use M3U8 playlists to deliver live news, sports, and entertainment channels to Smart TVs, smartphones, and computers without needing cable or satellite dishes.

• Compatible Software. Because they are standard text playlists, they work across widely available media players like VLC Media Player, TiviMate, and IPTV Smarters.
